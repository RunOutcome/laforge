# Dungeon Party

The forge as a candlelit tavern table. The rail is a parchment roster pinned to dark wood. It holds a tavern sign with the machine's name, a quest log of spaces with wax seals, and the party: every agent, marked by what it is doing. Panes are iron-bound slates, and the open space is lettered in gold as the current quest. Rail layout, dark.

Both modes: dark is the candlelit tavern table; light is a daylight parchment map on pale oak (the roster, seals and d20 are unchanged).

| State | Shown as |
| --- | --- |
| working | crossed swords on a candlelit token |
| blocked / error | a red d20, "your roll", because only you can roll it; the slate glows red and a big d20 sits in its corner |
| done | a green star token, with "quest complete" on the slate |
| idle | a crescent moon: resting |
| lost pane | "Revive at the inn" over its resume actions |

    la skin install ./skins/dungeon-party
    la skin use dungeon-party    # or pick "Skin: Dungeon Party" in ⌘K

System faces only (Herculanum, Copperplate, Palatino, with fallbacks). Apache-2.0.
